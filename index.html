🎯 What Is This?

⚡ Quick Start

Get Started in 3 Steps

1. Install dependencies:

$ pip install anthropic pandas numpy
$ export ANTHROPIC_API_KEY='your-key-here'

2. Run minimal example:

$ python minimal_example.py

3. Run full workflow:

$ python complete_workflow.py

✨ Key Features

Data Extraction

  • ✓ PDF parsing with sentence-level citations
  • ✓ Custom schemas for any study type
  • ✓ Batch processing multiple papers
  • ✓ Streaming with real-time progress

Statistical Analysis

  • ✓ Odds ratios, risk ratios, SMD
  • ✓ Fixed-effect meta-analysis
  • ✓ Random-effects (DerSimonian-Laird)
  • ✓ Heterogeneity statistics (Q, I², τ²)
